Modbus 远程调试台 · 桌面端 UI/UX 专业改版方案 appui-preview · v3.2.3 Desktop Workbench

与手机端小程序 ui-preview.html (v3.2) 共享同一套工业视觉与 WS2812B 固件灯语（发数据 TX 赭红 / 收数据 RX 墨绿 / 结构深蓝灰），彻底重构桌面端截图中的「手机单列大框堆叠、核心数据表缺失、高危红框视觉疲劳、操作记录刷屏占满半屏」四大痛点。

v3.2.3 修订：Modscan 只保留一个「启动连续扫描 / 停止轮询」按钮并固定在滚动区顶部； 去掉实时寄存器表的「点位说明」列；模块设置页不再提供广播名称修改 UI（远程改不了，现场蓝牙才能改）； 主工作区禁止卡片被 flex 压缩，长表格不会再挤扁工具栏/按钮； 浅色主题下顶部链路带一并转浅色（`--hdr-*` token），不再留一条突兀的深色横杠。

1. 告别「单列大框 + 铅笔图标」原图痛点 01

  • 现状问题：原版将波特率、数据位、校验位、停止位拆成 7 个全宽大框，改一个参数要点一次铅笔，执行按钮与参数分离。
  • 专业方案：采用桌面级紧凑表单网格 + 分段直选控件 (Segmented Control)，同组参数合成一张卡片，顶部实时预览 19200 · 8E1 并一键下发。

2. 补齐核心「寄存器表与报文台」原图痛点 02

  • 现状问题：原版 Modscan 只有左侧 6 个参数框，看不见寄存器实时数据表；串口页报文内容只有一行铅笔输入，TX/RX 报文流被藏在右上角按钮里。
  • 专业方案：桌面端采用「左参数控制 + 右实时数据表」双栏布局，点击任意寄存器行即可弹窗改值并预览 FC06 报文。

3. 解除「全屏红框疲劳」与黄条遮挡原图痛点 03

  • 现状问题：原版把几乎所有字段都套上红框与「高危」字样，导致真正报错时不醒目；底部「已下发，等现场回执…」黄条直接遮住下方卡片。
  • 专业方案：仅在写入动作按钮与未保存脏状态上克制标注高危；下发回执移入底部固定状态栏，绝不遮挡表单。

4. 右栏「操作记录 + 报文流」分屏聚合原图痛点 04

  • 现状问题：右侧 45% 面积被重复的「已通知现场打开工具」「现场没响应」巨型卡片刷屏，关键的原始 HEX 报文流却看不到。
  • 专业方案：右栏升级为「实时报文流 TX/RX + 协作记录」上下分屏，连续相同动作自动折叠为 ×3，离线提示提炼为顶部可恢复横幅。

三、桌面端 UI/UX 改版对照清单（供前端/Electron/Tauri 实现直接落地）

保持现有通信协议、指令名与状态字段不变，仅重构桌面端组件层级与布局网格。

界面 / 模块 原截图存在的问题 专业设计改版方案（本文件已实现）
全局色彩与灯语 全黑底配暗红细框，几乎所有卡片都标红「高危」，产生严重视觉疲劳；缺乏与小程序端一致的品牌感。 引入与小程序 ui-preview.html 同源的深蓝灰结构色 + WS2812B 固件灯语色（发数据 TX #e0705e 赭红、收数据 RX #56b881 墨绿），并支持 Dark Pro / Light Sync 一键切换。
模块设置页
模块 (图1)		 当前串口、广播名、写入名称、波特率、数据位、校验位、停止位拆成 7 个竖排大框；每次修改要点小铅笔图标；底部黄色回执浮层直接挡住「读当前参数」。 拆分为「蓝牙广播标识卡」+「485 侧串口参数卡」双栏；串口卡顶部大字实时显示组合预览 19200 · 8E1 及「未写入」脏标记；数据位/校验位/停止位改为分段按钮一键直选；下发回执移入底部固定状态栏。
RTU 快速设置
RTU (图2)		 每个寄存器占一个大红框，显示「未读取现值」，无法直观对比「模板默认值 vs 设备现值 vs 准备写入的新值」。 顶部集成「目标站号 + 模板切换 + 读取设备现值 (FC03)」工具条；下方采用结构化参数对照表，同屏展示寄存器地址、模板值、读取现值、内联枚举选择器及实时报文预览，支持单项写入与写后自动读回校验。
串口调试页
串口 (图3)		 「发送一帧」和「循环发送」变成顶部两个孤立的大框，真正的「报文内容」却缩在下方单行铅笔框里，且同屏看不到收发回包。 合并为一体化帧发送台：模式切换 (HEX/ASCII)、预设快捷帧、等宽 HEX 输入框、自动计算的 CRC16 高亮尾缀、循环间隔与发送按钮紧凑排布；下方直接内嵌收发分色控制台。
Modscan 页
Modscan (图4)		 左半屏只有 6 个参数设置框，完全看不到扫描出来的寄存器列表与数值变化。 采用「左参数控制栏 (290px) + 右实时寄存器网格」布局；顶部四区切换（03 保持 / 04 输入 / 02 离散 / 01 线圈）；表格实时展示 DEC、HEX、变值高亮闪烁，点击任意行直接弹出 FC06 写入框。
右侧操作记录与报文流 占掉窗口近一半宽度，全是重复的「已通知现场打开工具」「现场没响应」巨型卡片；而核心「报文流」却要另点按钮。 右侧升级为「实时 485 报文流 + 协作记录」上下分屏坞（可切单屏）；连续重复的切页/离线记录自动折叠并显示 ×3 计数徽章；现场离线提炼为顶部醒目可恢复横幅。
底部状态栏 右下角裸露英文 result 应答无法识别 busy 空闲，缺乏可读性。 升级为工程状态栏：左侧为「现场返回」+「实时指令下发进度胶囊」，右侧为带色彩语义的最近应答耗时 FC03 OK (62ms) 与总线状态 空闲 Idle / 轮询中 Polling。
